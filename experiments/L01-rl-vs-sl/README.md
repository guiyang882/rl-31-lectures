# L01 · 随机策略 vs 规则策略

第 01 讲「从监督学习到强化学习：目标变了什么」的配套实验。

## 实验目的

在 CartPole-v1 上建立两个基线：

- **随机策略**：每个动作等概率采样，代表"什么都没学"的水平；
- **规则策略**：把人类对物理的理解写成 if-else（杆往哪倒就往哪推），代表"手写的先验知识"能达到的水平。

这两个数字是后面所有实验的参照系。第 10 讲我们从头写 DQN，要看它能不能超过规则策略——如果连手写规则都打不过，那"学习"就没意义了。

## 环境

```bash
pip install gymnasium matplotlib numpy
```

已验证：Python 3.13.14 / gymnasium 1.x / numpy 2.x / matplotlib 3.x。

## 运行

```bash
cd experiments/L01-rl-vs-sl
python compare.py
```

固定 `seed=42`，100 局，结果完全可复现。

## 输出

- `results.csv`：每局的原始回报（随机 / 规则两列）
- `return_curves.png`：回报曲线（浅色原始 + 10 回合滑动平均）

运行后终端会打印两种策略的平均回报、标准差、最值。

## 实测结果（seed=42，100 局，gymnasium 1.4.0）

| 策略 | 平均回报 | 标准差 | 最小 | 最大 |
|---|---|---|---|---|
| 随机 | 25.22 | 14.12 | 9.00 | 87.00 |
| 规则 | 500.00 | 0.00 | 500.00 | 500.00 |

## 关键观察点

1. 随机策略平均只活 25.22 步，标准差 14.12——纯靠运气，且波动大。
2. 规则策略每局都顶到环境上限 500，方差为 0。
3. **别急着下"手写规则就够了"的结论**：这条规则是先验知识（杆角、角速度、位置）的手工编码，换个环境就失效。RL 要学的是"从交互中自己找策略"的能力，第 10 讲的 DQN 要在不知道这些先验的情况下逼近这个满分基线。
4. 两者差距不是"调参"能填平的，是**有没有利用环境结构信息**的差距——这正是第 01 讲要讲的"数据与目标的根本变化"。
