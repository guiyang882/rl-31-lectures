# 强化学习 31 讲

> 从机器学习背景出发，一路学到 Agent 轨迹上的强化学习与训练。
> 每讲配套：LaTeX 讲义 PDF + 可运行实验 + 公众号文章。

## 关于这个系列

这不是一份"看完就忘"的教程，而是一条**贯穿式学习路径**：从监督学习到强化学习的目标变化开始，
经过表格型方法、深度价值方法、策略梯度与 PPO，进入大模型 RLHF，最后落到 Agent 轨迹上的 GRPO 训练。
所有实验共享一条主线，逐步升级，最后长成一个会调用工具的多步 Agent。

- **受众**：有机器学习基础（熟悉 Python、概率、梯度下降、PyTorch），强化学习从零起步
- **终点**：能独立把一条 Agent 轨迹写成 MDP，设计奖励，用 GRPO 训练并诊断崩坏
- **节奏**：每周 2 讲，约 4 个月完成（待确认）
- **配套输出**：讲义 PDF（下载打印/汇编成书）+ 公众号文章（精简版）

## 如何编译讲义

需先安装 TeX Live（含 ctex 中文支持），然后：

```bash
cd latex
./build.sh main      # 生成 main.pdf
```

详见 [`latex/README.md`](latex/README.md)。
